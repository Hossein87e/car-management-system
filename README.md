## 🇬🇧 English Section

### 📌 About the Project
A comprehensive Python-based desktop application designed for managing car inventory, user reservations, and customer interactions. The system features a fully functional Role-Based Access Control (RBAC) separating Admin and User privileges, ensuring secure and organized data flow.

### 🚀 Key Features
*   **Role-Based Authentication:** Secure login system with distinct interfaces for Administrators and normal Users.
*   **Admin Dashboard (CRUD):** Dedicated pages for admins to Add, Edit, and Delete cars from the inventory seamlessly.
*   **User Experience:** Interactive user pages including a Shopping Cart (`cart_page`) and Reservation system.
*   **Customer Engagement:** Built-in commenting system (`comment_backend` & `comment_page`) for users to leave reviews and feedback.
*   **Local Database Management:** Efficient and lightweight data storage using structured JSON files (secured and excluded from public view).

### 🛠️ Tech Stack
*   **Language:** Python
*   **Architecture:** Modular design separating UI pages and backend logic
*   **Database:** JSON-based local storage

## 🇮🇷 بخش فارسی

### 📌 درباره پروژه
یک سیستم نرم‌افزاری جامع تحت دسکتاپ که با زبان پایتون برای مدیریت موجودی نمایشگاه/فروشگاه خودرو، رزروها و تعامل با مشتریان توسعه یافته است. این برنامه دارای سیستم احراز هویت سطح‌بندی شده (مدیر و کاربر) است که امنیت و نظم گردش اطلاعات را تضمین می‌کند.

### 🚀 ویژگی‌های کلیدی
*   **احراز هویت هوشمند:** سیستم لاگین امن با تفکیک کامل پنل کاربری و پنل مدیریت.
*   **داشبورد مدیریت (عملیات CRUD):** دارای صفحات اختصاصی برای افزودن، ویرایش و حذف خودروها توسط ادمین سیستم.
*   **تجربه کاربری یکپارچه:** امکان مشاهده خودروها، افزودن به سبد خرید و ثبت درخواست رزرو برای کاربران عادی.
*   **سیستم تعامل با مشتری:** مجهز به بخش ثبت و مدیریت نظرات کاربران روی محصولات.
*   **مدیریت داده‌ها:** استفاده از ساختار بهینه JSON برای ذخیره‌سازی اطلاعات پایگاه داده (به صورت ایمن و محلی).

### 🛠️ تکنولوژی‌های استفاده شده
*   **زبان برنامه‌نویسی:** پایتون (Python)
*   **معماری:** طراحی ماژولار و تفکیک فایل‌های رابط کاربری (UI) از منطق برنامه (Backend)
*   **پایگاه داده:** JSON
